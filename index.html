Taqyon Personal Automation

Owner-operated personal productivity tools and encrypted backup storage.

What these tools do

Fiqri Farish operates these private tools for his own authorised accounts and projects. They are not a public sign-up service and are not affiliated with or endorsed by Google.

  • Backup storage: a dedicated connection uploads and retrieves client-side-encrypted recovery data in Google Drive. The backup repository is being prepared; this page does not certify that backups or recovery tests are complete.
  • Project document publication: a separate connection creates and maintains selected project documents in Google Drive, and reads back those published files to verify the results.
  • Other personal Workspace tasks: separately authorised utilities can assist with email, calendar, contacts, documents and spreadsheets when requested by the owner. These permissions are not required by the two Drive-only connections described above.

Why Google access is requested

The backup and project-publication connections request the drive.file permission: access to files created by, opened with, or explicitly made available to the relevant app. They use separate credentials. Neither of these connections requests access to Gmail messages, Calendar events or every existing file in Drive.

Other owner-authorised Workspace clients may request additional service-specific permissions, as shown on their individual Google consent screens. The privacy notice explains the data handling.

Private tools, public information only

This website hosts only an informational homepage and privacy notice. It does not provide access to the automation system, account data, project documents, credentials or backups. There is no sign-in form, payment facility or public application endpoint here.
